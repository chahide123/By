# موقع التوصيل (على طريقة Glovo)

الصفحات بعد التشغيل:
- `/` الزبون: مطاعم، بقالة، صيدلية، "أي شيء"، السلة، تتبع الطلبات
- `/panel.html` السائق وصاحب المتجر
- `/admin.html` الإدارة (تتبع الطلبات النشطة + تفعيل/تعطيل المتاجر والسائقين)

## التشغيل (Node 20.6+ و PostgreSQL)
```bash
createdb delivery
cp .env.example .env        # ثم املأ JWT_SECRET (الأمر داخل الملف)
npm install
npm run db                  # إنشاء الجداول
npm run seed                # حسابات ومتاجر تجريبية (كلمات المرور تُطبع مرة واحدة)
npm start                   # http://localhost:3000
```

## الأدوار
التسجيل من الموقع ينشئ حساب **زبون** فقط. لترقية حساب:
```sql
UPDATE users SET role='admin' WHERE email='you@example.com';  -- courier | store_owner
```

## ملاحظات
- الدفع عند الاستلام فقط، والأسعار تُحسب في الخادم.
- تتبع السائق يعمل والصفحة `/panel.html` مفتوحة على هاتفه.
- للنشر استعمل HTTPS (الموقع يرسل كلمات المرور وJWT).
